# B-W12-08 auditor negative controls

Controls prove the auditor is not vacuous. Corruption is confined to isolated
disposable databases created for the control; ordinary scenario databases are
never mutated. Where a PostgreSQL constraint makes a corrupt row impossible,
the control records the enforced rejection instead of bypassing the guard.

| Control | Target | Seeded condition | Expected | Observed | Isolation | Notes |
| --- | --- | --- | --- | --- | --- | --- |
| `CTRL-01A` | AUD-01 | Direct SQL: the same reservationId current on two Drivers. | PostgreSQL rejects the duplicate reservation identity. | **ENFORCED_BY_CONSTRAINT (23505 ux_drivers_reservation_id)** | isolated Driver database (control_constraints) | Cross-driver reservation uniqueness is storage-enforced. |
| `CTRL-02A` | AUD-02 | Direct SQL: AVAILABLE with reservation references. | PostgreSQL rejects the incoherent row. | **ENFORCED_BY_CONSTRAINT (23514 chk_drivers_coherence)** | isolated Driver database (control_constraints) | Constraint enforcement demonstrated instead of bypassing the guard to fabricate a detection. |
| `CTRL-06A` | AUD-06 | Direct SQL: one result identity attached to two NO_DRIVER rounds. | PostgreSQL rejects the duplicate terminal identity. | **ENFORCED_BY_CONSTRAINT (23505 ux_matching_rounds_result_message_id)** | isolated Matching database (control_matching_constraints) | One logical result identity is storage-enforced. |
| `CTRL-06B` | AUD-06 | Direct SQL: NO_DRIVER without a persisted result identity. | PostgreSQL rejects the identity-less terminal. | **ENFORCED_BY_CONSTRAINT (23514 chk_matching_rounds_no_driver_result)** | isolated Matching database (control_matching_constraints) | New NO_DRIVER terminals cannot omit their durable result identity. |
| `CTRL-EMPTY` | AUD-01..08 | Fresh schemas with zero rows in every authority table. | No PASS from an empty dataset. | **AUD-01=NOT RUN, AUD-02=NOT RUN, AUD-03=NOT RUN, AUD-04=NOT RUN, AUD-05=NOT RUN, AUD-06=NOT RUN, AUD-07=NOT RUN, AUD-08=NOT RUN** | isolated empty databases (control_empty) | Demonstrates non-vacuity: an empty dataset yields NOT RUN, never a green result. |
| `CTRL-UNREACHABLE` | AUD-04/AUD-07 | Trip/Matching connection strings point to an unreachable server. | BLOCKED, never PASS. | **AUD-04=BLOCKED, AUD-07=BLOCKED** | driver-only database + unreachable authorities | An unreachable authority cannot produce a business verdict. |
| `NEG-04A` | AUD-04 | Trip assignment reservationId changed while the Driver kept the original reservation. | AUD-04 FAIL for exact identity disagreement. | **FAIL / DRIVER_TRIP_DISAGREEMENT** | isolated Trip + Driver databases (neg_disagreement) | Trip row remains internally coherent; only the cross-service comparison can catch it. |
| `NEG-06A` | AUD-06 | Second RESERVED attempt added to an already RESERVED round. | AUD-06 FAIL with multiple RESERVED attempts. | **FAIL / MULTIPLE_RESERVED_ATTEMPTS** | isolated matching database (neg_contradictory) | No production code path creates two RESERVED attempts in one round; the auditor detects ledger corruption. |
| `NEG-06B` | AUD-06 | NO_DRIVER terminal result identity with its MatchingFailedV1 Outbox intent deleted. | AUD-06 FAIL for missing durable terminal intent. | **FAIL / MISSING_OR_MISMATCHED_FAILURE_INTENT** | isolated matching database (neg_missing_intent) | The real terminalizer commits state and intent atomically; deletion simulates storage corruption outside the code path. |
| `NEG-07A` | AUD-07 | Cancelled Trip, cleanup intents marked complete, Driver row still RESERVED. | AUD-07 FAIL: a sent/confirmed cleanup is not proof the reservation was released. | **FAIL / LEAKED_RESERVATION** | isolated Trip + Driver databases (neg_leak) | Directly exercises the mission rule that release completion must be read from the Driver authority. |
| `NEG-07B` | AUD-07 | Recognized release obligation aged 2 h while the Driver stayed RESERVED. | AUD-07 FAIL beyond the accepted cleanup policy. | **FAIL / STUCK_CLEANUP_OBLIGATION** | isolated Trip + Driver databases (neg_stuck_cleanup) | Distinguishes recognized-pending cleanup from an unbounded leak. |
| `NEG-07C` | AUD-04/AUD-07 | Fresh open release obligation and a still-RESERVED Driver at business quiescence. | AUD-04 and AUD-07 FAIL; recognized pending is only acceptable in mid-flight observation. | **AUD-04=FAIL, AUD-07=FAIL / UNRESOLVED_CLEANUP_AT_QUIESCENCE** | isolated Trip + Driver databases (neg_fresh_cleanup) | Proves the observation mode is enforced, not merely recorded. |
| `NEG-08A` | AUD-08 | 2 h-old PENDING Outbox row, UNKNOWN attempt and PROCESSING round. | AUD-08 FAIL for every stale unresolved category. | **FAIL / STUCK_PENDING_OUTBOX,STUCK_UNRESOLVED_ATTEMPT,STUCK_PROCESSING_ROUND,TRIP_SAGA_SCOPE** | isolated Driver + Matching databases (neg_stuck) | Age policy: 15 min for pending outbox, unresolved attempts and PROCESSING rounds. |
| `NEG-08B` | AUD-08 | Fresh PENDING Outbox row in a relay-quiesced observation. | AUD-08 FAIL: quiesced relay state requires pending = 0. | **FAIL / PENDING_OUTBOX_AT_QUIESCENCE** | isolated Driver database (neg_relay_pending) | Complements the age-policy control: no-relay modes accept fresh pending within policy, relay-quiesced modes do not. |
